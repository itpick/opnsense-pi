OPNsense for Raspberry Pi

Flash-and-boot OPNsense 26.7 (FreeBSD 15.1) images. The UEFI firmware is already on the disk.

Unofficial community build, not supported by Deciso. Fine for labs; keep a working router nearby.

Works

Raspberry Pi 4

  • Onboard Ethernet genet0 as LAN
  • USB 3 NIC (RTL8153 / AX88179) as WAN
  • UEFI: pftf/RPi4 v1.53
  • No AES hardware, so VPNs are CPU-bound

Experimental

Raspberry Pi 5

  • Boots, but the onboard Ethernet is not supported yet (RP1)
  • USB NIC as WAN/LAN: unverified
  • UEFI: rpi5-uefi v0.1, D0 boards (all 16 GB), SD boot
  • AES hardware on Cortex-A76

One-liner (Linux)

Writes the Pi 4 image straight to a disk. Replace /dev/sdX; everything on it is erased.

curl -fL https://github.com/itpick/opnsense-pi/releases/latest/download/opnsense-pi4.img.xz | xz -dc | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

Or, in Raspberry Pi Imager, choose Use custom and select the downloaded .img.xz.

First boot

  1. Update the EEPROM bootloader first (Raspberry Pi OS: sudo rpi-eeprom-update -a).
  2. Pi 4: press Esc at the UEFI splash, go to Device Manager → Raspberry Pi Configuration → Advanced Configuration, and disable Limit RAM to 3 GB.
  3. On the HDMI console, assign interfaces: LAN genet0, WAN ue0.
  4. Open https://192.168.1.1 and log in as root / opnsense. Change the password.

Build it yourself

git clone https://github.com/itpick/opnsense-pi && cd opnsense-pi && make image BOARD=pi4
