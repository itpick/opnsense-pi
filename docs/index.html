OPNsense for Raspberry Pi

Flash-and-boot OPNsense 26.7 (FreeBSD 15.1) images. The UEFI firmware is already on the disk.

Unofficial community build, not supported by Deciso.

Works

Raspberry Pi 4

  • Onboard Ethernet genet0 as LAN
  • USB 3 NIC (RTL8153 / AX88179) as WAN
  • UEFI: pftf/RPi4 v1.53
  • No AES hardware, so VPNs are CPU-bound

Works

Raspberry Pi 5

  • Onboard Ethernet rp1eth0 works (1 Gb/s; tested on a 16 GB board)
  • USB 3 NICs (RTL8156 2.5 GbE) attach as ue0, ue1, ... and carry traffic
  • Measured as a home router on a 1 Gb/s AT&T line: about 830 Mbit/s down, 700 up, with Suricata on; CPU 18% average across cores (details)
  • UEFI: rpi5-uefi v0.1, D0 boards (all 16 GB), SD boot
  • AES hardware on Cortex-A76

Throughput ceiling on the Pi 5

Theoretical; not yet measured with 5 GbE dongles.

LinkCeiling
Onboard Ethernet1 Gbit/s
Each blue USB 3.0 port5 Gbit/s signalling (USB 3.x Gen 1, 8b/10b coding), so at most 4 Gbit/s of data. A 5 GbE RTL8157 dongle can link at 5 Gbit/s, but on a PC's Gen 1 port it moved 3.47 Gbit/s in iperf3 (4.70 on Gen 2). Expect about 3.5 Gbit/s per port. Each port has its own USB controller in the RP1 chip.
RP1 ↔ SoCPCIe 2.0 x4, about 16 Gbit/s each way, shared by both USB ports and the onboard Ethernet. It is not the limit with two dongles.
DriverFreeBSD's ure driver stops at the RTL8156: it has no RTL8157 support, in FreeBSD 15.1 (OPNsense 26.7) or in FreeBSD's main branch as of November 2026. 2.5 GbE (RTL8156) is the fastest supported USB NIC, about 2.35 Gbit/s per port.

One-liner (Linux)

Writes the Pi 4 image straight to a disk. Replace /dev/sdX; everything on it is erased.

curl -fL https://github.com/itpick/opnsense-pi/releases/latest/download/opnsense-pi4.img.xz | xz -dc | sudo dd of=/dev/sdX bs=4M conv=fsync status=progress

Or, in Raspberry Pi Imager, choose Use custom and select the downloaded .img.xz.

First boot

  1. Update the EEPROM bootloader first (Raspberry Pi OS: sudo rpi-eeprom-update -a).
  2. Pi 4: press Esc at the UEFI splash, go to Device Manager → Raspberry Pi Configuration → Advanced Configuration, and disable Limit RAM to 3 GB.
  3. On the HDMI console, assign interfaces: LAN genet0 (Pi 4) or rp1eth0 (Pi 5), WAN ue0.
  4. Open https://192.168.1.1 and log in as root / opnsense. Change the password.

Build it yourself

git clone https://github.com/itpick/opnsense-pi && cd opnsense-pi && make image BOARD=pi4
